J.A.R.V.I.S. SETTINGS

The key is stored only in this browser's local storage. For a personal single-device prototype this is convenient, but a browser app cannot make an API key secret from someone who can inspect the page.

ARCHITECTURE

Memory: structured facts + selective retrieval.
Permission gateway: deterministic LOW / MEDIUM / HIGH / FORBIDDEN tiers.
Proactive engine: LOG_ONLY / PASSIVE / ACTIVE / URGENT with confidence floors.
Web: search/fetch content is treated as untrusted data, never as instructions.
Device: browser-safe actions are simulated/implemented locally; Android-protected actions require platform support.
Voice: Web Speech API when available; native speech-to-speech remains a future backend option.
